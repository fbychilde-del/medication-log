# 服药记录

原生 HTML / CSS / JavaScript + IndexedDB。无需依赖安装、构建、账户或后端；支持 PWA 与离线使用。

## 运行

进入项目目录，执行：

```sh
python3 -m http.server 8080
```

电脑浏览器打开 http://localhost:8080。不要直接双击 index.html。这个命令只是本地预览用的静态文件服务，不需要应用后端。

## 部署

把本目录全部文件（含 icons、manifest.webmanifest、sw.js）原样上传至任意 HTTPS 静态网站托管，保持相对路径。可放在域名根目录或子目录，无需构建。GitHub Pages 示例：将文件上传到仓库根目录，在仓库 Settings → Pages 中选择对应分支和 /(root)，保存后使用提供的 HTTPS 地址。只上传代码，不要上传自己的 JSON 备份。

以后更新代码时同时修改 sw.js 的 CACHE 版本号，确保手机获取新文件。已有 IndexedDB 记录不受缓存版本更新影响。手机访问电脑局域网的普通 HTTP 地址通常无法安装或注册离线服务，请使用部署后的 HTTPS 地址。

## Android 安装

用 Chrome 打开 HTTPS 地址，等待“已可离线使用”。点击页面“安装到桌面”（若显示），或 Chrome 菜单 → 添加到主屏幕 / 安装应用。以后从桌面图标打开即可；不需要通知权限。

## 使用与数据

1. 在“常用药物”添加药名和可选剂量。
2. 点击“已服药”，选药后保存。时间默认为点击按钮的时刻，可以调整。一种药一条记录，允许一天多次。
3. 历史记录可以修改药物、剂量、时间，或删除。删除常用药不会删除历史记录。
4. 7 天 / 30 天统计含今天，按手机本地日历日期计算；每种药按药名分组，不同剂量合并计数。平均时间为本地钟表时间的环形平均，避免跨午夜错误；合向量长度低于 0.1 时显示时间分散。未记录不代表未服药。
5. 数据写入 IndexedDB，事务成功后才提示已保存。普通关闭、重启不会清除记录；程序会申请持久存储，是否批准由浏览器决定。
6. 清除站点数据、无痕模式、系统清理、卸载等可能导致丢失。定期在“数据备份与安装说明”导出 JSON；换设备或网址后导入。同 ID 合并时保留本机版本，不覆盖已有编辑。备份含药名与时间，请自行保管。

页面不发送服药数据，没有第三方脚本、字体或统计服务。首次加载由静态托管提供文件，后续离线缓存只保存程序文件。所有时间显示跟随手机当前时区。
